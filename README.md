# Heart Rate Monitor 0.19.7

幅112の細い左サイドバーに「ライブ」「履歴」「設定」をアイコンと短いラベルで配置しています。通常の項目は枠を省き、選択中の項目は淡い背景と左端の細い線で示します。「履歴」ではCSV出力も利用できます。設定画面は「外観と言語」「接続と常駐」「データ保存」「OSC設定」が一列に続くフォームです。各セクションは区切り線で整理し、タブ内で縦スクロールできます。「保存して適用」は右下に固定しています。タブを切り替えても未保存の入力とスクロール位置を保ち、保存後も設定タブとスクロール位置を維持します。

履歴画面の「記録のリズム」で、今日を含む過去365日分の記録カレンダーを確認できます。1マスがWindowsのローカル日付の1日を表し、有効な心拍（0 bpm・接触なしを除く）の件数を色の濃さで示します。ライトではティール、ダークではブルーのアクセントを使い、マスは幅いっぱいに長方形を敷き詰める形で、記録のない日は灰色で表示します。件数の区切りは0件／1〜599件／600〜3,599件／3,600〜10,799件／10,800件以上で、心拍数の高低や装着時間を示すものではありません。日付にマウスを重ねると件数を確認でき、クリックまたはTabでカレンダーへ移動→矢印キー→Enterでその日の履歴を表示できます。記録日数と合計件数は見出しの右に表示し、履歴を開いた時・「最新の記録へ」・履歴表示中の毎分に更新します。保存期間により削除された記録は集計に含みません。過去365日より前の記録も、保存されていれば従来の全体グラフから確認できます。

履歴の日時指定は削除しました。履歴ページは縦横ともスクロールせず、グラフ・全体グラフ・CSV出力・保存期間を画面内に表示します。最小ウィンドウなど、領域が狭い場合はページ全体を縮小して収めます。長いエラーや出力先は省略表示し、マウスを重ねると全文を確認できます。

表示幅（Time span）は、ライブ・履歴とも定型ボタンに加えてスライダーでも調整できます。左で短く、右で長くなり、現在の幅を常時表示します。最小1分、ライブは最大1時間、履歴は全記録まで選べます。矢印キーでも微調整できます。長期間の履歴でも短い範囲を選びやすいよう、スライダーは右に進むほど大きく変化します。調整後も定型ボタンで10分などへ戻せます。

標準BLE Heart Rate Service対応の心拍センサー（COOSPO HW706など）を自動検出・接続し、心拍数をSQLiteに記録・可視化しながらVRChatへOSC送信するWindowsデスクトップアプリです。日本語／英語UI、ライト／ダークテーマ、タスクトレイ常駐に対応しています。外部サービス・アカウント不要です。英語の説明は [README.en.md](README.en.md) を参照してください。

## 起動

`artifacts\HeartRateMonitor.exe` を実行します。Windows 10/11の64ビット版、.NET Framework 4.8、Bluetooth LE対応アダプターが必要です。Windows 11では通常.NET Framework 4.8以降が導入済みです。

1. 心拍センサーを装着して電源を入れ、WindowsのBluetoothを有効にします。
2. アプリを起動すると、自動で心拍センサーを検索・接続します。検索は約8秒。見つからない場合も5秒待って再検索するので、アプリ起動後にセンサーの電源を入れても接続できます。
3. ライブ画面は横幅いっぱいの心拍グラフが中心です。上部に現在の心拍数・最小／平均／最大・最終受信時刻を表示し、10分・30分・1時間のボタンで表示幅を選べます。記録・OSCのカードは表示せず、記録と送信は裏で継続します。OSCの送信状況と単発テストは「設定」にあります。ライブ・履歴のグラフには、表示期間の有効な実測値の平均を水平の破線と数値ラベルで表示します。データがない期間には平均線を表示しません。カーソルをグラフに合わせると、近くの測定点の時刻・心拍数を確認できます。受信ごとに自動保存します。受信ログの表は表示しません。
4. 「履歴・CSV」は、メイングラフの下に保存中の全期間を見渡せる細い全体グラフを表示します。最初は10分幅。両端のハンドルで拡大・縮小（最小1分）、選択範囲の中央や上端のつまみで左右に移動でき、メイングラフが即時追従します。範囲外のクリックでも移動できます。10分・30分・1時間・6時間・24時間・全体のボタン、前後の期間、最新への移動にも対応します。表示幅は保存中の期間に収まるよう調整され、短い記録の全体グラフは10分幅を確保します。Tabで中央・開始・終了を選択し、矢印キーで1分（Shift併用で10分）、Home／Endで端まで調整できます。操作中は実測値から集約した概要グラフを表示し、終了後に詳細・統計・平均線を確定します。CSVは確定した表示期間の元の測定値を出力します。記録は初期設定では無期限に保存します。設定で有限の保存期間を選ぶと、期間を過ぎた記録は自動削除され、復元・CSV出力できません。
5. 「停止」で検索・接続・自動再接続・記録・OSC送信を停止します。「自動接続」で再開できます。閉じるボタンは初期設定ではタスクトレイに格納します。記録とOSCは継続します。トレイアイコンのダブルクリック、またはEXEの再実行で復帰します。終了はトレイの右クリックメニューから行います。終了時は保存キューを書き出します。

標準Heart Rate Service (0x180D) / Heart Rate Measurement (0x2A37) を使用します。アプリから直接機器を検索・接続します。見つからない場合は電源、距離、WindowsのBluetooth設定、およびスマートフォン等の別アプリによる接続を確認してください。

## 自動接続と手動選択

- 接続順は **前回接続に成功した検証済み機器 → Heart Rate Serviceを広告する、またはWindowsに心拍サービスが登録されている機器** です。前回の機器が検索に出なくても先に接続を試し、接続できなければ次の候補へ進みます。メーカー名・型番で優先しません。名前だけでは自動接続対象にせず、サービスが検索に出ない機器は「詳細」から選択して接続できます。各センサーの互換性は実機確認が必要です。
- センサーの機能はGATTの心拍サービスと通知特性で確認します。名前だけで測定データとして扱うことはありません。
- 候補に接続できない場合は次の候補を試します。候補がなければ検索を繰り返します。Bluetoothが一時的にオフでも再試行します。
- 前回の検証済み機器が広告に見つからなくても、他の候補より先に保存した機器への接続を試します。
- BLE広告だけでなく、Windowsに登録された心拍サービスとペアリング済みBLE機器も検索します。メーカー名や型番によらず心拍サービスを持つ機器を候補に含め、GATTで心拍通知を確認します。
- 古い設定に残った一般のBluetooth機器を、自動接続候補にはしません。広告がない場合の保存先への再接続は、修正版で心拍サービスへの接続に成功した機器だけが対象です。
- 一度接続した後はその機器に再接続します。切断時に別の人のセンサーへ切り替わるのを防ぎます。
- 別の機器を選ぶ場合は「停止」→「詳細」→「再検索」→選択→「選択した機器に接続」。手動検索には名前のある一般のBluetooth機器も表示します。
- 「設定」で起動時の自動接続と切断後の自動再接続を個別に変更できます。起動時の設定は次回起動から有効です。「停止」は現在の起動中だけの一時停止です。

## 外観

「ライブ」「履歴・CSV」と同じ並びから開く「設定」にテーマ、表示言語（日本語／English）、自動接続、常駐動作をまとめています。「保存して適用」で反映し、次回起動にも引き継ぎます。再起動は不要です。Windowsに合わせる場合はOSのアプリモード変更にも追従します。設定画面のOSCテストは保存済みの設定を使います。

## センサーが見つからないとき

Windows設定で心拍計が登録済みでも、広告に出てこない場合があります。修正版は登録済み心拍サービスからも接続を試みます。Bekoやスマホなど別アプリが同時に接続している場合は、そちらの接続を終了してください。

接続欄の「ログをコピー」で検索・接続の経過をコピーできます。同じログは保存フォルダーの `connection.log` に残します。機器名、検出経路、Windowsエラー番号、失敗した段階を記録し、心拍数はログに含めません。ログは起動ごとに更新し、直近250行に制限します。

### AccessDeniedの場合

現行版では心拍サービスに `RequestAccessAsync()` を実行し、許可後に共有モードで開いてから通知特性を取得します。登録済みサービスも共有モードで開きます。アクセス拒否や共有違反では自動再試行を停止します。ログの「アクセス要求」「共有オープン」で拒否された段階を確認できます。

参考ソフトの `HeartRate.exe` がタスクトレイに残っている場合は、そちらを終了して「自動接続」で再開してください。タイトルバーの `Heart Rate Monitor 0.19.7` が今回の版の目印です。実機接続の成功は未確認です。

接続欄は検索中、検出、接続中、接続済み・受信待ち、心拍受信中を区別します。サービスに接続しただけでは「心拍受信中」にしません。アクセス拒否・他アプリ使用中・Unreachable・タイムアウトには対応する案内と再接続ボタンを表示します。詳細な診断ログにはWindowsのエラーや日本語の技術情報が含まれます。

## VRChat / OSC

初期送信先は `127.0.0.1:9000` (UDP) です。設定を保存すると次の心拍通知から適用されます。

| 値 | 初期パラメーター名 | 実際のOSCアドレス | OSC型 |
| --- | --- | --- | --- |
| 心拍数 | `VRCOSC/Heartrate/Value` | `/avatar/parameters/VRCOSC/Heartrate/Value` | `i` (Int32) |
| 心拍割合 | `HRPercent` | `/avatar/parameters/HRPercent` | `f` (Float32) |

- VRChatのアクションメニューで **OSC → Enabled** を有効にします。
- アバターのExpression Parameters / Animatorに同じ名前・型のパラメーターを用意してください。必要に応じてアバターのOSC設定をリセットしてください。
- パラメーター名だけでも、`/avatar/parameters/` から始まる完全なアドレスでも入力できます。ホストはIPv4またはIPv6アドレスを指定します。
- `HRPercent = clamp((bpm − 最小) / (最大 − 最小), 0, 1)`。初期値は最小0、最大200なので72 bpm → 0.36です。既存アバターに合わせて変更できます。
- IntはVRChatの範囲に合わせて0〜255に制限します。SQLiteには元の16ビット心拍数を保存します。
- 0 bpm、またはセンサーが「接触なし」を通知した場合は保存のみ行い、OSCは送りません。停止・切断中も送信しません。アバター側の値は最後に受信した値のままです。
- 設定画面の「送信状況とテスト」に有効／無効、送信待ち、最終送信時刻、送信先、Int／Floatの実際の値、送信エラーを表示します。テスト心拍数（初期80）を指定して2値を1回送信できます。テストはSQLite・履歴・CSVに保存しません。OSCが無効ならテストも送りません。実データ受信中は次の通知でテスト値が上書きされます。停止中も明示的なテスト送信は利用できます。
- 「UDP送信」はOSへの送出成功を示します。VRChatが受信・適用したかは、VRChatの **OSC Debug** で確認してください。

## 記録と履歴

保存先は `%LOCALAPPDATA%\HeartRateMonitor\` です。

- `heartrate.db`: SQLiteデータベース（WAL、FULL同期）。UTCミリ秒、心拍数、接続セッション、機器、接触状態、RR間隔・消費エネルギー（通知された場合）を保存します。
- `settings.json`: 送信先・パラメーター・変換範囲・自動接続・自動再接続・前回接続した機器・テーマ・言語・トレイ設定。設定更新時は以前の設定を `.bak` に残します。以前のバージョンの設定も読み込めます。
- 保存期間の初期値は **無期限** です。「設定 → データ保存 → 保存期間」で **無期限・1日（24時間）・7日・30日・90日・1年（365日）** を選び、「保存して適用」で反映します。有限の期間では、現在時刻から指定日数を超えた記録を起動時・保存期間の変更時・実行中の毎分の確認で自動削除します。既存の記録も対象で、削除後は復元・CSV出力できません。必要な記録は変更前にCSVへ書き出してください。無期限に戻しても削除済み記録は復元されません。保存期間の項目がない旧設定は無期限へ移行します。無期限では記録に応じて容量が増えるため、空き容量を確認してください。バックアップはアプリ終了後に保存フォルダーごとコピーします。
- CSVはUTF-8 BOM付き。UTCとローカル時刻、心拍数、接触状態、RR間隔などを含みます。RRはミリ秒をセミコロンで区切ります。
- 履歴の統計とグラフは0 bpm・接触なしを除外します。データベースとCSVには全通知を残します。履歴グラフは最大約400区間の平均値と最小〜最大を描きます。
- 5秒以上通知がないと現在値を「—」にし、20秒以上通知がないと再接続します。失敗後は5秒待機。自動モードでは再検索の約8秒も加わります。1回の接続タイムアウトは25秒です。

## ビルド・検証

外部NuGetパッケージは不要です。ビルドには64ビットWindows、.NET SDK（Roslynコンパイラー）、Windows 10/11 SDK（Windows.winmd）が必要です。実行時は.NET SDKもWindows SDKも不要です。Windows付属の `winsqlite3.dll` と.NET Framework / WPF / WinRTを使用します。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Test
.\artifacts\HeartRateMonitor.exe
```

`build.ps1` はこのPCの.NET FrameworkとWindows SDKの参照を使ってコンパイルします。ソースは `HeartRateMonitor\`、自動テストは `tests\Tests.cs` です。デバイスの通知解析、OSCのバイナリー・UDP実送信、変換・設定検証、SQLite再オープン、期間検索、CSV、終了時の保存をテストします。

標準ビルドは `artifacts\version-X.Y.Z\` に版ごとの成果物を保存し、検証成功後に最新版のEXE・設定ファイル・ZIPを `artifacts\` 直下へコピーします。ZIPにはEXE・設定ファイル・日本語／英語READMEを含みます。旧版と検証ファイルは各バージョンフォルダー内にまとめます。`version-0.0.0\` は製品バージョン未設定の旧ビルド・検証ファイルの保管先です。実行中のEXEは上書きできないため、最新版の更新時はトレイの「終了」で閉じてください。

UIだけを別のデータ保存先で起動・描画するスモークテスト:

```powershell
.\artifacts\HeartRateMonitor.exe --data-dir .\artifacts\version-0.19.7\verification\smoke --smoke-test
```

指定フォルダーに `smoke-ja-dark-0.png` などの日本語／英語 × ダーク／ライト × 3タブの画像と、履歴の制約付き表示・設定の最下部の画像を計20枚出力して終了します。0はライブ、1は履歴、2は設定タブです。タブの選択表示、設定のスクロール、未保存入力の維持、保存後の選択タブとスクロール位置を検証し、結果を `smoke-checks.txt` に記録します。設定の保存も行います。必ず専用のデータフォルダーを指定してください。架空の心拍データの生成やBluetooth接続は行いません。

実際のWindows UI操作による起動時の自動検索、停止、再開、検索中の終了の検証（対話デスクトップが必要）:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\ui-smoke.ps1
```

一時フォルダーにテストと明記した2時間分の測定値を入れた専用DBを作り、本来の保存先を変更しません。自動テストは通知解析・接続・OSC・設定・保存期間の移行／変更・長期履歴／CSVを検証します。UI操作では検索の停止・再開、履歴の範囲選択、表の削除、英語への切り替え・保存、トレイ格納、EXE再実行による復帰、明示的な終了を確認します。日本語／英語・両テーマ・3画面の描画も確認しています。接続・切断の状態遷移は疑似トランスポートでも検証しています。作成環境では登録機器の列挙がWindowsエラーで失敗するため、登録済みHW706の実接続確認は利用環境で必要です。

実機での最終確認はHW706とVRChatを起動して行ってください。受信、切断後の再接続、過去データ、OSC Debugでの2値受信を順に確認します。

## 構成

- `BluetoothMonitor.cs`: BLE検索、通知購読、再接続・キャンセル
- `AutoConnector.cs`: 自動検出の優先順位・候補選択・再検索・停止
- `Models.cs`: 通知解析、設定、心拍レコード
- `Store.cs`: SQLite保存・検索・集計・CSV
- `OscSender.cs`: OSC 1.0のInt32 / Float32エンコード、UDP送信
- `RecordingEngine.cs`: 受信キュー、保存と送信、終了時の排出
- `MainWindow*.cs` / `HeartChart.cs`: WPF画面、履歴の時間操作、グラフ
- `TrayHost.cs`: タスクトレイ常駐、復帰・終了メニュー
- `Presentation.cs`: 日本語／英語の表示、接続状態とエラーの分類、表示期間
- `Theme.xaml` / `ThemeManager.cs`: 共通コントロール、テーマ切り替え・Windows設定追従

ウィンドウ上端のツールバーにある太陽／月アイコンから、どの画面でもライト／ダークを切り替えられます。テーマは即時保存されます。Windows追従に戻す場合は設定で選び直してください。約0.36秒でテーマ色とアイコンが変化します。画面画像は保持せず、終了後はアニメーションを解放します。Windowsでアニメーションを無効にした場合やハイコントラスト時は動きを省略します。

ツールバーの空白やアプリ名の部分はドラッグで移動、ダブルクリックで最大化／復元できます。「設定」は「ライブ」「履歴・CSV」と同じ通常のタブです。設定内容を縦スクロールして編集し、変更は下部の「保存して適用」で反映します。ほかのタブを選ぶと画面を切り替えられます。設定の表示中も記録は継続します。ダークモードはグレーを基調とした配色です。

ライブ・履歴のメイングラフはCtrl＋ホイールで拡大・縮小できます（上方向で拡大、下方向で縮小）。履歴はカーソル位置の時刻を基準にし、下の全体グラフとも同期します。ライブは最新時刻を右端に維持し、1分〜1時間の幅で変更します。履歴は1分〜保存中の全期間です。Ctrlなしのホイールはページのスクロールとして動作します。
メイングラフを左右にドラッグすると分析区間を色付きで選択し、平均・最小・最大・件数・期間と、その区間だけの平均線を表示します。クリック、Esc、右クリックで解除できます。統計は開始時刻を含み終了時刻を含まない範囲で計算します。履歴はSQLiteの元の実測値、ライブは現在のライブグラフに保持している元の実測値を使用し、集約グラフの平均を再平均しません。0 bpm・接触なしは除外します。表示期間を変更すると分析区間を解除します。CSVの対象は表示期間で、分析区間の選択だけでは変更しません。

接続UIは、機器名・状態と「接続」「停止」「詳細」の細いバーです。「詳細」はポップアップで開き、機器選択・再接続・接続ログコピーを使えます。開閉しても画面やグラフのサイズは変わりません。「閉じる」、Escキー、外側のクリックで閉じられます。常時表示する操作を絞り、心拍グラフのスペースを確保します。ツールバーのテーマ・設定アイコンは16px、同じ線幅とボタンサイズに統一しました。タイトル部分はバー自身がマウス操作を受け取り、ドラッグで移動、ダブルクリックで最大化／復元します。最大化状態からのドラッグでは元の大きさに戻して移動します。
グラフの時間軸は読みやすい大きさで表示し、一定の時刻間隔を基準に目盛りを配置します。20分以下の範囲では秒まで表示します。区間選択の開始・終了は大きく表示し、軸の下にも選択時刻を示します。所要時間は時間・分・秒で表示し、1分未満の選択ではミリ秒も区別できます。日付をまたぐときは日付も補足します。
