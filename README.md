# Heart Rate Monitor 0.20.0

標準BLE Heart Rate Service対応センサーの心拍を受信し、SQLiteに記録してグラフで確認できるWindowsデスクトップアプリです。VRChat向けOSC送信、CSV出力、日本語・英語UI、Light・Dark・Systemテーマ、タスクトレイ常駐に対応しています。外部アカウントは不要です。

[English](README.en.md)

## 動作環境と起動

Windows 10/11（64ビット）、.NET Framework 4.8、Bluetooth LE対応アダプターが必要です。センサーは標準Heart Rate Service（`0x180D`）とHeart Rate Measurement通知（`0x2A37`）に対応するものを使います。COOSPO HW706などを想定していますが、各機器との互換性は実機確認が必要です。

配布ZIPを展開し、`HeartRateMonitor.exe` を実行します。ソースからビルドした場合は `artifacts/HeartRateMonitor.exe` です。EXEと同梱の `HeartRateMonitor.exe.config` を同じフォルダーに置いてください。

1. WindowsのBluetoothを有効にし、センサーを装着して電源を入れます。
2. 初期設定では起動時に自動検索・接続します。前回成功した検証済み機器を優先し、その次に標準心拍サービスを広告する、またはWindowsに心拍サービスが登録された機器を試します。メーカーや名前による優先はありません。
3. 「ライブ」で心拍数とグラフを確認します。受信値は自動保存します。「履歴」で過去の記録を確認し、表示期間をCSVへ出力できます。
4. 接続バーの「停止」で検索・接続・再接続を停止し、「接続」で再開します。手動選択・再接続・ログコピーは「詳細」にあります。
5. 閉じるボタンは初期設定ではトレイに格納し、記録・OSCを継続します。完全終了はトレイの「終了」です。アイコンのダブルクリックやEXEの再実行で復帰できます。

## グラフと履歴

ライブと履歴はグラフを中心に表示し、受信データの表は表示しません。表示期間の最小・平均・最大、平均線、カーソル付近の測定値を確認できます。

- 表示幅はボタンまたはスライダーで変更します。最小1分、ライブは最大1時間、履歴は全記録まで。履歴の初期幅は10分です。
- `Ctrl`＋ホイールで拡大・縮小します。履歴の全体グラフでは選択範囲を移動し、両端をドラッグして幅を変更できます。
- メイングラフを横にドラッグすると、選択区間の時間・平均・最小・最大・件数を確認できます。
- 「記録のリズム」は今日を含む365日分の有効な測定件数を表示します。日付を選ぶとその日の履歴へ移動します。
- CSVは確定した表示期間の元の測定値を出力します。ドラッグした分析区間とは別です。0 bpm・接触なしの記録も含まれます。

## 設定とOSC

「設定」では、左のカテゴリを選ぶと右側の設定内容が切り替わります。各カテゴリはスクロールせずに操作できます。カテゴリやライブ・履歴を行き来しても未保存の入力を保持し、保存後も選択中のカテゴリに留まります。言語、テーマ、自動接続・再接続、トレイ常駐、保存期間、OSCを編集し、「保存して適用」で反映します。上部の太陽・月アイコンによるテーマ変更は即座に保存します。

OSCは初期設定で有効、送信先はUDP `127.0.0.1:9000` です。VRChat側でOSCを有効にし、アバターに対応するパラメーターを用意します。

- Int32：`/avatar/parameters/VRCOSC/Heartrate/Value`。心拍数を0〜255に制限します。
- Float32：`/avatar/parameters/HRPercent`。初期設定は0〜200 bpmを0.0〜1.0へ変換します。式は `clamp((bpm - 最小) / (最大 - 最小), 0, 1)` です。

IP・ポート・パラメーター名・換算範囲は変更できます。送信状態と単発テストは設定画面にあります。テストは保存済み設定で2値を一度だけ送信し、測定記録は作りません。UDP送信成功はVRChatでの受信・適用を保証しません。0 bpm・明示的な接触なしは保存しますが送信しません。

### 切断・無受信時のOSC動作

設定のOSC欄で次の2モードを選択し、「保存して適用」で反映します。

- **最終値を維持**：無受信時は送信せず、受信側の最後の値を変更しません。
- **無受信時に両方へ0を送信**（初期値）：指定時間（1〜3600秒、初期値5秒）通知が届かなければ、Intに`0`、Floatに`0.0`を一度送信します。起動からまだ通知がない場合や、手動停止中も対象です。0 bpm・接触なしを含む各通知の受信で待ち時間を数え直します。送信状況には無受信による0送信と表示し、測定記録には追加しません。正常な測定が再開すると通常送信に戻ります。

この項目がない旧設定にも初期値を適用します。すでに保存したモード・秒数は維持します。

OSC無効時とアプリ終了後は0を送信しません。無受信時間はPCの時計変更の影響を受けない経過時間で判定します。設定変更時点ですでに時間を超えていれば、適用後に0を送信します。単発テストは受信扱いにせず、無受信時はテスト値も0に置き換わります。UDP送信成功は受信側での適用を保証しません。

## データ保存とバックアップ

通常の保存先は `%LOCALAPPDATA%\HeartRateMonitor\` です。`heartrate.db` が測定記録、`settings.json` が設定、`connection.log` が接続診断です。

保存期間の初期値は**無期限**です。1・7・30・90・365日にも変更できます。有限の期間では既存の記録も対象に、起動時・方針変更後・動作中の1分ごとの確認で古い記録を自動削除します。**削除後は復元・CSV出力できません。無期限に戻しても復元されません。** 必要な記録は変更前に書き出してください。保存期間が未設定の旧設定も無期限として扱います。

バックアップはトレイから終了した後、保存先フォルダー全体をコピーしてください。CSVは測定値の出力用で、復元用ではありません。無期限では使用容量が増えるため、空き容量を確認してください。

## 開発と検証

WPF / .NET Framework 4.8、Windows WinRT BLE API、OS付属の `winsqlite3.dll` を使用します。.NET SDK（Roslyn）とWindows SDKメタデータが必要です。NuGetは使用しません。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Test
```

開発ビルドは `artifacts/HeartRateMonitor.exe` を上書きし、設定ファイル・日英README・配布ZIPも `artifacts/` 直下に配置します。ZIPにはEXE・設定ファイル・日英READMEを含みます。実行中のEXEを置き換える前に、トレイからアプリを終了してください。

`artifacts/` 直下の生成物と検証ファイルは開発用です。ビルドや検証ではバージョンを確定せず、バージョン別フォルダーも自動作成しません。`artifacts/version-X.Y.Z/` は明示的に指示されたバージョン確定時のスナップショット用、既存の `version-0.0.0/` はバージョン不明の旧生成物用です。

UI変更時は対話可能なWindowsデスクトップで次の検証も行います。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\ui-smoke.ps1
.\artifacts\HeartRateMonitor.exe --data-dir .\artifacts\verification\render --smoke-test
```

UIスクリプトは `ISOLATED UI TEST` と明示した一時データを使います。描画スモークテストは日本語・英語とLight・Dark・Systemの画面を確認し、PNGと `smoke-checks.txt` を出力します。テスト用の設定も保存するため、`--data-dir` には必ず通常の保存先とは別の専用ディレクトリを指定してください。

自動テストは通知解析、接続制御、OSC、SQLite・CSV、保持期限、履歴・分析などを確認します。実機での動作確認は別です。HW706の実通知・切断復帰・長時間稼働・VRChatへの適用は、実機を使った検証が必要です。

Beko.BluetoothHeartRateOSCは動作上の参考とし、実装は独立して作成しています。
